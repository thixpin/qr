# Security Policy

Security reports are welcome for the current [live site](https://qr.thixpin.me/) and the code on the repository's `main` branch.

Email [thixpin@gmail.com](mailto:thixpin@gmail.com) to report a suspected vulnerability privately. Include the affected page or commit, steps to reproduce, and the potential impact. Use sample values in screenshots or examples, especially for QR payloads, contact details, or Wi-Fi credentials.

Give the maintainer time to investigate before publishing exploit details. For ordinary bugs, use the [issue tracker](https://github.com/thixpin/qr/issues).
