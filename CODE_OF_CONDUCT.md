# Code of Conduct

Treat people with respect in project issues, pull requests, and other project spaces. Critique the work, give specific feedback, and allow room for different experience levels and backgrounds.

Harassment, discriminatory language, personal attacks, threats, and sharing someone else's private information without permission are unacceptable.

Report concerns privately to the maintainer at [thixpin@gmail.com](mailto:thixpin@gmail.com). Include links or context that help explain what happened. The maintainer will limit sharing to what is needed to address the report and may remove content or restrict participation.
